
# Achievement Tracker

A simple web application for creating and tracking personal achievements and goals made by Chris Vega

## Features

* User registration and login
* Create achievements with a title, description, category, and XP value
* Mark achievements as completed
* Delete achievements
* Track completion progress by category
* User-specific achievement data

## Technologies

* HTML
* CSS
* JavaScript
* Tailwind CSS
* Supabase
* Netlify

## Categories

* Personal
* Work
* School
* Social
* Financial

## Deployment

The application is deployed using Netlify, with Supabase providing authentication and database functionality.
